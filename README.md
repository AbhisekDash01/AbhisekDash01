## 🚀 Featured Projects

### 1. CineBook – Full-Stack Movie Ticket Booking Platform

A full-stack movie ticket booking application built using Java 21, Spring Boot, and MySQL. It allows users to explore movies, view available shows, select seats, and manage bookings through an interactive interface.

**Tech:** Java 21, Spring Boot, Spring Data JPA, Hibernate, MySQL, Docker, HTML, CSS, JavaScript

- Developed REST APIs for movie listings, shows, seat availability, bookings, and cancellations.
- Designed a relational database with nine tables.
- Implemented transactional booking workflows to maintain consistency during seat reservations.
- Built an interactive frontend with seat selection and an admin panel.
- Deployed the frontend on Netlify, backend on Render using Docker, and database on Aiven.

🔗 [GitHub Repository](https://github.com/AbhisekDash01/CineBook) | [Live Demo](https://sage-kulfi-7ff393.netlify.app/)

### 2. Airport Runway Queue Simulator

A Java-based airport runway simulation demonstrating priority-based flight scheduling and multithreaded processing.

**Tech:** Java 21, Spring Boot, PriorityQueue, Multithreading, REST APIs

- Implemented priority-based flight scheduling using Java PriorityQueue.
- Implemented independent flight generation and runway processing threads.
- Exposed REST APIs to manage simulation operations and monitor flight status.
- Built a dashboard to visualise simulation activity.

🔗 [Backend](https://github.com/AbhisekDash01/airport-simulator-backend) | [Frontend](https://github.com/AbhisekDash01/airport-simulator-frontend) | [Live Demo](https://clinquant-biscotti-602bfa.netlify.app/)
